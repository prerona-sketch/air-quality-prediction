# Air Quality Prediction Using LSTM and GRU

## Overview
This project aims to predict future air pollution levels using historical air-quality and weather data. It explores time-series forecasting using machine learning and deep learning.

## Objectives
- Analyze historical PM2.5 concentration.
- Clean and preprocess time-series data.
- Visualize air pollution trends.
- Implement baseline, LSTM, and GRU models.
- Compare forecasting performance.

## Dataset
**Beijing PM2.5 Dataset** — UCI Machine Learning Repository.

Dataset: https://archive.ics.uci.edu/dataset/381/beijing+pm2+5+data

## Models
- Baseline forecasting
- Linear Regression
- LSTM (PyTorch)
- GRU (PyTorch)

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Tech Stack
Python, Pandas, NumPy, Matplotlib, scikit-learn, PyTorch.
